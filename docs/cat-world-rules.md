# 猫咪能量世界规则

## 核心规则

- 能量只能通过学习获得，包括拼写挑战、完整挑战、好句阅读等成长体系指标。
- 猫咪商城里的商品都消耗能量，不额外产出能量。
- 商品价格以后以后台“猫咪商城”为准，代码里的价格只作为默认值。
- 前台购买时必须展示本次扣除积分和购买后剩余积分。

## 商品类型

- 猫粮：可重复购买，购买后进入背包；点击使用会摆进房间并消耗 1 份库存。
- 玩具：一次性解锁，点击使用后提升猫咪心情，记录最近互动时间。
- 装修：一次性解锁，购买后出现在房间；可拖动位置，点击保存布局后持久化。
- 配色：一次性解锁，必须先拥有对应装修；点击已拥有装修可切换已购买颜色。
- 名猫：长期目标，购买后房间里会多一只猫；每只猫有自己的性格和想法。
- 食物、玩具和装修都可以绑定一只偏好的猫；偏好食物会额外补体力和心情，偏好玩具会额外加心情，偏好装修会减少心情消耗。

## 猫咪状态

- 红色条代表猫咪体力。
- 蓝色条代表猫咪心情。
- 每个账号里的每只猫每天有独立的 agent 日表，包括每日情绪、专注、好奇、捣蛋值、作息、当前行为和事件记录。
- 每日 agent 随机种子由账号、日期和猫咪共同决定，同一只猫在不同账号里会有不同的当天状态、当天目标和破坏抽签。
- 猫咪体力会按照每只猫的性格、运动量、当前行为和房间道具逐小时变化，前台用 `+/-` 显示。
- 猫咪心情会按照每只猫的性格、运动量、每日情绪和喜欢的家具逐小时变化，前台用 `+/-` 显示。
- 不同猫的休息阈值不同；低于阈值时原地休息，达到阈值后可以在房间里走动和互动。
- 晚上按照每只猫的作息判断是否睡觉；夜猫性格的猫在夜间仍可能巡逻。
- 睡觉时体力会恢复，心情稳定或小幅恢复；休息时会少扣，探索或夜巡时会多消耗。
- 当天很高兴会缓解心情下降，当天不高兴会加重心情下降；摆出喜欢的家具会减少心情消耗。
- 猫咪档案会展示每只猫偏好的食物、玩具和家具，前台道具卡也会标出哪只猫喜欢。
- 猫咪档案和 CAT-OS 会展示当前小时变化原因、道具减耗值和喜欢家具数量，方便判断为什么这只猫扣得多或少。
- 心情差、当天不高兴、捣蛋值高的猫更容易盯着道具，存在弄坏家具或玩具的风险。
- 当猫咪当天目标是捣蛋预警时，房间里会显示感叹号，靠近目标道具后出现粉色预警气泡和小晃动。

## 食物有效期

- 三文鱼能量碗：默认 30 分钟。
- 金枪鱼罐头：默认 45 分钟。
- 羊奶布丁：默认 60 分钟。
- 食物摆进房间后优先给体力最低的小猫。
- 食物会按时间逐步被吃掉，每次推进会给目标猫增加体力和心情。
- 食物吃完或到期后，房间里的食物显示会消失。

## 损坏与维修

- 损坏行为尽量发生在猫咪心情差、当天不高兴或捣蛋值高的时候，概率会按当天情绪偏移后的心情计算。
- 被损坏的家具和玩具仍会显示在房间里，但会有破损标记。
- 损坏的家具和玩具不参与猫咪喜好加成、减耗缓解和互动。
- 点击房间里的损坏道具或右侧背包里的损坏道具，可以花费维修能量修好。
- 维修费用按后台价格或默认价格的一定比例计算，测试清零可以在后台猫咪商城处理。

## 房间布局与互动

- 家具可以在房间里拖动，拖动后需要点击保存布局才会持久化。
- 购买过的配色会显示在对应家具卡片下方，点击小圆点可切换颜色。
- 猫咪移动时会根据方向翻转，向左走时头朝左、尾巴在右，并带有转身反馈。
- 猫咪会根据每日目标、喜欢的家具、当前食物和体力状态选择移动目标。
- 猫咪在自由活动时也会按好奇度和心情主动靠近自己喜欢的玩具或家具；心情偏低时更容易去找喜欢的玩具。
- 猫咪主动靠近喜欢的玩具或家具时，会按冷却时间写入今日 agent 事件，避免刷屏但能保留当天行为轨迹。
- 睡觉和低体力休息时，猫咪会优先落在喜欢的家具、云朵地毯、阳光窗台或当前食物附近，不再只是默认排队站位。
- 房间里的每只猫会显示自己的短状态牌，例如睡觉、休息、想玩、盯着道具或巡逻；高优先级目标会让猫咪初始位置更靠近目标物。
- 猫咪转身时只翻转身体，状态牌、Zzz 和预警符号保持正向显示，不会出现镜像文字。
- 猫咪可点击区域应略大于像素身体，避免移动过程中点不到猫。

## 素材策略

- 当前版本用 Phaser 绘制像素房间、道具和猫咪，优先保证交互、拖动和状态规则稳定。
- 后续猫咪、家具、食物、背景都可以替换成阿里云 AI 生成的透明 PNG 或精灵图。
- 素材替换时保持同一套数据接口：商品 id、分类、价格、库存、房间坐标不变。
